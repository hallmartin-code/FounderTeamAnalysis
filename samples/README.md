# Sample decks

Drop test decks here. They are gitignored (this README is not).

The acceptance tests expect three kinds:

| File | Kind | Exercises |
|---|---|---|
| `deck.pdf` | text-based PDF | pdfplumber text path |
| `scanned.pdf` | image-only / scanned PDF | vision rasterization path |
| `deck.pptx` | PowerPoint | python-pptx shape walk + speaker notes |
